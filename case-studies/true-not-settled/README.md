# True but Not Settled

**An adaptive remedial pathway built from option-level error analysis.**

A learner preparing for a graduate admissions test answered 2 of 5 critical-reasoning questions correctly. Instead of prescribing "more practice," this case traces all six wrong option-level judgements to one root cause, then designs a five-unit pathway that closes the gap, proves it closed, and checks that it lasts.

## Origin and sanitization

This design began as a diagnostic exercise on one learner's five-question response set. For this portfolio:
- **All five questions are newly written** by the author to reproduce the same error pattern.
- **The learner's responses and notes are re-created** on the new questions. Timings follow the original pattern.
- **Platform-specific labels, levels and benchmarks are replaced** with neutral terms. Where a live engagement would use a platform's own benchmark, the value is marked **[Benchmark]**.
- Nothing identifies the learner or the organization.

## Evidence labels

Every finding and threshold carries one label, so a reviewer can see what is observed and what is inferred.

| Label | Meaning |
|---|---|
| **[Certain]** | Follows directly from the question text or the learner's written work |
| **[Judgement]** | An inference from limited data, or a design choice; the reason is given |
| **[Benchmark]** | In a live engagement, set from the learning platform's own progression rules; placeholder value shown |
